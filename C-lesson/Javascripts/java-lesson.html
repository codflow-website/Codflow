What is Java & JVM Architecture?

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. Its core principle, "Write Once, Run Anywhere" (WORA), is powered by the Java Virtual Machine (JVM).

Java Execution Pipeline

Java source code (`.java`) is compiled into bytecode (`.class`) by `javac`, which is then interpreted or compiled to machine code by the Java Virtual Machine (JVM).

Java Memory Management

Java automatically manages memory using Heap and Stack allocations, alongside Garbage Collection to free up unused objects.

Stack Memory:

Stores local variables, primitive data types, and method invocation call frames. Execution is fast and follows Last-In-First-Out (LIFO) order.

Heap Memory:

Stores all Java objects and instance variables dynamically. Objects created here are monitored by the Garbage Collector.

Automatic Garbage Collection runs in the background to clean up unreferenced objects in Heap memory.

Class & Object Structure

Every Java application consists of classes. Here is a simple layout of a standard class structure with a `main` entry point.

// Java Class Hierarchy & Main Method Structure
public class Main {
├── public static void main(String[] args) {
│   ├── System.out.println("Hello, Java!"); <-- Execution Starts Here
│   └── Object obj = new MyObject();
└── }
}

Key Takeaways

  • Platform Independence is achieved through Bytecode running on platform-specific JVMs.
  • Garbage Collector manages memory lifecycle automatically in the Heap.
  • Strongly Typed syntax ensures errors are caught at compile time rather than runtime.
  • Object-Oriented principles (Encapsulation, Inheritance, Polymorphism, Abstraction) form the core architecture.
